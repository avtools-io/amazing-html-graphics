# Contribution Guidelines

Please ensure your pull request adheres to the following guidelines:

- This is a software and resources compilation for professional HTML graphics and OGraf workflows; commercial and non-open-source entries are welcome when they are relevant and amazing.
- Entries should help broadcast or motion-picture technicians and engineers, creative media professionals, or media-focused software developers author, develop, integrate, operate, evaluate, test, or learn HTML graphics.
- Please search previous suggestions before making a new one, as yours may be a duplicate.
- Please make an individual pull request for each resource entry and keep it to one logical entry commit.
- Use the following format: \[RESOURCE\]\(LINK\) – DESCRIPTION.
- Begin software and product descriptions with an accurate availability label such as **Open source (LICENCE)**, **Source available**, **Commercial**, **Hosted/SaaS**, **Open core**, or **Freeware**.
- Link to canonical project, product, publisher, or specification pages rather than resellers, mirrors, or listicles.
- Describe OGraf compatibility precisely and provide canonical evidence; generic HTML or browser-source support is not direct OGraf support.
- Disclose when a project is archived, deprecated, experimental, beta, a proof of concept, or apparently unmaintained.
- Keep descriptions short, factual, and free of vendor superlatives.
- End all descriptions with a full stop/period.
- Order entries alphabetically within each category.
- Do not use affiliate or referral links.
- Check your spelling and grammar.
- New categories or improvements to the existing categorisation are welcome.

Thank you for your suggestions!
